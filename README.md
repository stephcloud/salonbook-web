# Claude Next.js Starter

Template for Next.js frontends built with Claude Code.

## Use
1. GitHub: click **Use this template** and name the repo `<project>-web`.
2. Clone it, edit the top section of `CLAUDE.md` (project, routes, backend API, env vars).
3. Run `claude`, then `/scaffold-web` once to generate the app.

## Included
```
CLAUDE.md                    project memory, conventions, rules
.claude/settings.json        permissions (blocks .env, force push)
.claude/skills/              /scaffold-web /new-page /new-component /test /commit
.claude/agents/              code-reviewer, test-writer, ui-reviewer
.env.example
```

## Improve the template
When a skill or rule proves useful in a project, copy it back here.
